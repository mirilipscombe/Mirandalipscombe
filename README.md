# Miranda Lipscombe — Portfolio

A static website ready for GitHub Pages. No build tools or installation required.

## Publish
1. Create a public GitHub repository (for example `portfolio`).
2. Extract this ZIP and upload its **contents** to the repository root. `index.html` must be at the root, alongside `style.css`, `site.js` and the project folders. Keep the `assets` folder and its contents.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Once deployment finishes, Pages will show your website link: `https://YOUR-USERNAME.github.io/portfolio/`.

If your repository is named `YOUR-USERNAME.github.io`, the site appears at `https://YOUR-USERNAME.github.io/` instead.

## Edit
- `index.html`: homepage and introductory text.
- `style.css`: colours, typography and responsive layout.
- Each project folder contains its own `index.html`.
- `assets/`: all 29 locally hosted portfolio images.
- `site.js`: photograph lightbox.

The enquiry button links to the existing Adobe Portfolio contact page. Replace that link with `mailto:YOUR-EMAIL` when you are ready. YouTube videos remain embedded from YouTube, and the GiveVision film remains embedded from Adobe's video player. Keep those source videos available; upload the GiveVision film to another video host if you want to remove its Adobe dependency.
